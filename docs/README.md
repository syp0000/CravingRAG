# Project documents

The main [README](../README.md) explains CravingRAG for a general audience. The files in
this folder preserve the detailed technical and research history.

| Document | What it contains |
|---|---|
| [DESIGN.md](DESIGN.md) | Original system design and the failures that motivated V2 |
| [DECISIONS.md](DECISIONS.md) | Architecture choices, rejected alternatives, and reasoning |
| [PLAN.md](PLAN.md) | Build history, scale-up procedure, known limits, and possible future V3 work |
| [diagrams/](diagrams/) | Static and interactive architecture diagrams |

Evaluation data and result reports stay in [`eval/`](../eval/) because they are part of
the reproducible experiment rather than general documentation.
